# Agent 后台自动执行：本地测试交付（2026-09-10）

## 实施范围与授权

用户允许测试期间默认启用自动能力及真实模型费用。此次将自动接续迁到服务端，不依赖浏览器轮询触发模型；未批量启动历史会话，未用用户现有作品作为修改测试夹具。

本地测试启动：`scripts/start-local-autonomy-api.ps1`。它默认设置 `LOOMIC_AGENT_AUTONOMY_TEST_DEFAULT=true`，只使用固定本地副本配置，遇到已有 API 端口时拒绝停止进程。生产默认仍关闭。后台签名使用独立 `LOOMIC_AGENT_AUTONOMY_SIGNING_KEY`，不替换浏览器的 Supabase JWT 验证配置。密钥只在进程内传递，不进入模型、任务记录或报告。

每个任务最多 24 次后台决策/检查预算、8 个图片方案、2 小时；一次后台决策最多 6 次主模型调用、30 次工具调用。因此“24 轮”不是“最多 24 次底层模型请求”。费用允许不等于无上限调用或取消权限确认。

## 已接入的闭环

- 服务端持久授权、任务版本绑定、租约领取、重复领取隔离、运行预算及停止。
- 原始用户意图和纠正保留；Skill/案例只是参考，不能扩大目标或授权。
- 用户真实多选画板才能产生多目标范围；独立 RLS 校验，执行时使用投影目标，不覆盖主目标或错误引用主图。
- 普通生图方案在授权范围内自动确认，交付后检查，工作流根据可信结果接续；有限视觉修复。
- 单图无工作流也依据精确 job/asset/source/revision 和实际验收结束，不把“已生成”当作“已验收”。
- 原生破坏性修改冻结命令并持久确认；幂等执行，确认后的回调及安全重试可以恢复，核验不重复修改。
- 原生修改和图片扣费/入队在事务提交处检查当前租约；停止后晚到的提交被拒绝，明确用户确认的冻结命令可独立完成。
- UI 读取服务端状态，不再由页面触发自动模型调用；旧会话/旧登录身份/旧 GET 不覆盖新设置，超时可恢复。

## 尚不能宣称“完整无人值守”的边界

1. 本轮没有真实收费图片从生成、交付、视觉验收到跨画板下一步的完整长链路验收；真实意图样本也还不够，且存在未通过案例。
2. 自动执行受已绑定设计任务及明确目标范围限制，不是对整个无限画布任意写入。无最终提交栅栏的工具、任意文件写入、后台递归委派、视频及模板替换未开放为自主写工具。
3. 新纠正会使旧授权失效；没有把前序多目标范围不经确认地自动继承为新范围。
4. 目标歧义、破坏性确认、检查不可用、预算耗尽或无法证明是否已执行的崩溃会暂停。不会为了“无人值守”绕过确认、猜测成功或盲目重发付费/写入。
5. 任务激活后授权写入失败的持久重建、所有原生单步/无选中目标场景、复杂多板首轮切换，以及完整重启混沌测试仍需扩展验收。
