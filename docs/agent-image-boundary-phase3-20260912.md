## 根因与修复

原确定性取消入口只处理待确认图片方案，无法取消已成为后台任务的生成。新增严格当前用户/workspace/session/canvas 的运行中图片取消路径，调用已有条件更新取消服务。

- 待确认方案优先，不能把取消新方案误解成取消旧任务。
- 仅取消 queued/running；多个候选不猜；命名必须唯一匹配。
- 问句、条件、否定和复合请求不按直接取消处理。
- 重复取消、已完成以及取消竞态按实际终态回执。
- 供应商请求未必可撤回；不能承诺第三方退款。晚到结果不放回画布，仍可能保留私有结果/checkpoint 供审计。
