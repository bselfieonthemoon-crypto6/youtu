# Agent 生图 / 改图链路验收（2026-09-08）

## 范围与结论

环境：本地测试副本，前端 `localhost:3020`，API `127.0.0.1:3002`，Supabase `127.0.0.1:54421`。使用独立 QA 项目，没有编辑用户原画布、对话或既有设计内容；没有关闭权限校验、修改模型目录权限或更改扣费规则。没有执行真实视频生成和支付订阅。

覆盖：需求与方案、确认与取消、带图修改、画板背景 / 主体、抠图后处理、异步任务、重复确认、断线恢复、资源存储和重新加载，以及本地图片工具。有限测试不能证明所有输入、所有供应商都永远不会失败。

## 截图中的 Failed to get response

原会话 `9c8e637a-070b-4e38-a8ed-e0cffd3f8f74` 的“黑色背景改为绿色”在 07:58:21 UTC 保存了用户消息，服务端记录了启动入口，但没有对应的新 Agent 运行记录，也没有进入生图调用。说明这次失败点在启动前置阶段，不是图片供应商返回失败。

旧代码在画布、会话、模型校验失败时通过 WebSocket 返回 `type:error`，前端却忽略这类消息，等 10 秒后统一显示英文。旧代码也会在长连接中继续使用握手时的登录凭证，而不是新消息携带的已刷新凭证。旧凭证过期场景已在回归测试中复现并修复；历史日志没有记录具体拒绝分支，因此不能把原截图的精确原因断言为某一种权限或模型错误。

## 已修复

1. 每次 WebSocket 命令重新验证当前凭证，且必须属于握手时的同一用户。过期、失效、跨用户凭证仍拒绝，绝不绕过 RLS。
2. Agent 启动请求、ACK、拒绝响应使用请求 ID 对应；超时撤销监听，迟到 ACK 不会串到下一次请求。一个连接不能同时积压两个启动请求。
3. 服务端前置异常得到捕获；前端立即显示有针对性的中文错误。确认操作的鉴权失败也不再无声等待。
4. 启动等待上限调整为 30 秒。断线时释放旧流监听和发送状态，重连重新加载持久消息；不自动重发生成请求。
5. 已完成任务再次确认返回已有成功结果，并刷新资源签名地址；保留既有元素 / 图层 ID。仍有重试次数的临时失败保持等待，不提示重新生图。
6. 画板图片结果与普通画布图片区分，避免恢复设计图层时，又在无限画布插入一份散图。
7. 非背景画板图片先把生成原图保存到私有存储，再执行本地抠图。同一个 job 的后处理重试读取原图存档，不重新调用生图供应商；本地进程意外退出时有限重试一次。抠图仍失败时保留原图，错误中提供原图素材 ID，不以有背景原图冒充抠图成功结果。
8. 切换到去背景操作时释放不参与该操作的 SAM / LaMa 模型与图像缓存，减少本地多模型常驻造成的内存压力；不改变 BiRefNet 模型、推理尺寸或抠图算法。

原图存档只保证“下载并存储成功后”的重试复用。若供应商已完成请求但返回连接中断，或者在原图存储成功之前进程退出，不能承诺绝对不重复上游调用。跨供应商的端到端 exactly-once 需要上游支持幂等请求 / 任务查询。

## 真实失败与限制

- 首轮老虎自动抠图时，Windows 本地 ML 进程以 `0xC0000005` 退出；同时高并发测试的 esbuild 明确报内存不足。该 job 第二次执行后成功，不能把第一轮记为通过。之后将回归测试限制为单 worker，并增加上述原图存档和本地重试保护。
- 本地 ML 模型仍受机器内存限制；保护措施减少丢失和重复生成，不意味着资源不足时仍必定成功。抠图质量也取决于原图，不等同于流程是否正确。
- 不对所有图片风格、全部模型供应商做穷举或承诺零失败。失效登录、无权限附件、不可用模型、明确取消、过期确认仍应被拒绝。
- 历史副本存在四个旧任务的资源引用不完整，worker 会记录历史恢复失败；与本次独立 QA 任务分开记录，本轮没有删除或伪造这些旧资源。

## 复跑

使用本地 env，不要使用根目录的云端 `.env.local`：

```powershell
node --env-file=artifacts/local-replica-20260907/app.env scripts/audit-local-agent-image-flow.mjs
node --env-file=artifacts/local-replica-20260907/app.env scripts/audit-local-agent-image-flow.mjs --resume
node --env-file=artifacts/local-replica-20260907/app.env scripts/verify-durable-image-flow.mjs
```

第一个命令会在独立项目中实际调用生图接口，可能产生供应商费用。`--resume` 复用已记录的任务，不能在上次任务状态不明确时创建替代任务。数据库验证在事务中执行并回滚，不更改余额、队列或设计；不要附加 `--apply`。
