# 按需加载工具

## 设计边界

- 服务端保留完整工具实现，不把全部参数 schema 常驻模型上下文。
- 默认只展示基础观察/任务入口及 request_tools；其余能力以轻量目录发现。
- request_tools 只切换当前阶段的可见工具，不执行操作、不授予权限、不修改预算。
- 可见集合必须与当前请求真实可用工具及自治/只读范围取交集。后端原有意图、目标、版本和费用校验继续执行。
- Skills 完整目录通过 list_skills 查询，正文仍通过 use_skill/compose_skills 加载；简单任务不强制加载 Skill。

## 本轮范围

工具和 Skill 目录的上下文减载，不是删除功能，也不是更改模型供应商额度。专用 create_design_boards 的生产注册/数据库链路属于另一个未完成入口，不能把减载测试当作该创建流程已经验收。

## 验证要求

首轮隐藏生图/导出/Skill 编排 schema；按需加载后可调用；切换阶段不无限累积；当前授权不允许的能力不可通过加载恢复；压缩预算应与最终模型绑定输入一致。

## 实测与部署

- 真实 DeepAgents 图测试完成 request_tools → list_skills → 替换为 read_file → 新用户消息清空旧选择。没有网络调用或作品写入。
- 相同设计任务样例首轮 5 个工具定义，估算工具 token 为 1,921，总输入 22,722；未经减载的同轮比较为工具 10,400、总输入 30,247。均为应用保守估算，不是账单。
- 184 项相关测试通过，TypeScript 检查通过。随后并发选择防护补充后，五项重点测试再次通过。
- 发现 DeepAgents 同名替换保留默认位置，单纯把自定义中间件放末尾不足以保证顺序；现显式组合意图 → 工具减载 → 压缩，并合并状态 schema。真实图断言预算与最终发送包相等。
- 本地 API 更新为 PID 37036，健康检查通过；未重试余额不足的请求，未重启独立 worker。
- 原生画板创建入口及实际收费生图不在本轮已验收项目内。
