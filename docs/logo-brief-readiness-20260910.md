# Logo 需求就绪检查

- “生成 logo”只提供了交付物类别，不是品牌设计需求。
- 先读取用户已提供的信息、有效品牌资料和附件，不把助手自己的风格提案当作用户事实。
- 品牌名称/准确文字（或明确无文字标志）和行业/用途是关键资料；风格、颜色不强制填写。
- 确认只授权执行需求明确的方案，不能填补品牌资料空白。
- 完整提示词、已有用户背景、参考图编辑、明确的无文字艺术创作不得机械套用问卷。
- 新增意图评测样例 I033/I034；评测器单测通过不代表真实模型已经通过这些样例。

服务端拦截限定为明显缺少资料的 Logo 请求；更复杂的自然语言需求就绪判断仍由 Agent 在生产规则下完成。
