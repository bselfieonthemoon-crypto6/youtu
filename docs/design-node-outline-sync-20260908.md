# 画板描边与选中框同步

用户截图中的灰框为 DOM 预览层描边，紫框为 Excalidraw 节点选中框，并非两个独立画板。普通拖动测试未稳定复现截图中的错位，因此不把事件遗漏认定为已证实的唯一根因。

修复采取单一边界来源：删除 DOM 描边，让 Excalidraw 画板矩形自身绘制细灰边和白色底。它和选择/拖动命中区域共享同一节点几何数据；不改变设计文档或设计导出内容。

预览内容继续订阅节点变化，并在指针移动、释放和窗口变化后读取当前坐标；增加 250ms 状态补同步、相同快照去重及清理。动画帧通知合并，不反复取消并推迟；修正角度单位为 Excalidraw 的弧度。

验证：design-node-overlay-layer.test.tsx 8 项通过（包含多缩放级别、无 change 通知时的补同步、旋转单位、无重复 DOM 描边）。真实 Chromium design-node-drag-sync.spec.ts 通过：拖动期间即同步，释放后从 (100,130) 到 (200,150)，拖动控制柄将尺寸由 260×460 调为 340×500，预览与已保存原生节点几何数据一致。测试使用独立画布 b17adf0a-e5f7-4283-91b2-25053b7ebedd，无生图 API 调用。
