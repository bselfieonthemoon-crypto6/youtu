### 图片编辑验证

使用 128×128 的确定性测试图片与蒙版。透明擦除、智能修复逐像素检查未涂抹区域不变，透明擦除中心 alpha 为 0；抠图允许输出裁切后的尺寸；图层拆分返回两层。这里验证功能链路，不代表所有复杂图片的分割质量。

本机 CPU 实测：透明擦除约 2.2 秒、智能修复约 2.1 秒、去背景约 95.5 秒、框选约 36.7 秒、拆分约 36.7 秒。不是性能基准，不可推算千图吞吐；本地模型推理仍是明显的等待来源。

## 修复项

1. 项目、会话更新/删除：数据库影响零行时不再虚报成功，正确返回 404。
2. 上传删除：保留 Supabase RPC 接收者，修复合法删除返回 500。
3. 画板编辑幂等：重复 add/remove 请求先检查持久化回执，再由 RPC 验权并返回原结果；避免重复应用命令导致假错误。
4. 模板引用：移除不存在的 `source_template_id` 字段查询；实例化是独立场景快照，不伪造引用关系。
5. Jobs：非法过滤参数、非法 UUID 在查询数据库前返回 400，避免 500。
6. Agent：拒绝目录之外的任意客户端模型覆盖；HTTP 空目录下保留服务端配置的 APIYI 默认，与 WebSocket 一致；已停用的 workspace 模型仍拒绝，不盲目改用其他模型。重启后 12 组集成通过。
7. OCR：不存在/不可访问画布与图片不再误报为上游识别失败；超大图片返回相应客户端错误。
8. 橡皮：限制羽化作用范围，不再改变蒙版外的透明度；Python 专项回归通过。
9. 测试入口：Vitest 不再误收集使用 Node 原生测试框架的 Worker 监督测试；新增单独的 `test:supervisor` 入口。
