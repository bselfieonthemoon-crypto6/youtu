# 原位画板验证记录

## 范围

独立开发入口 `/dev/inline-artboard`，非开发环境返回 404。未替换正式画布、未访问用户文档或调用生图 API。测试使用内置 SVG 图像、文字和独立 localStorage 草稿。不是已上线功能或最终 UI。

运行服务：`http://localhost:3010/dev/inline-artboard`。原 3000 端口验证时不可连接，未改变正式服务配置。

## 浏览器实测

使用真实 Chrome、Excalidraw 和项目 FabricObjectEditor，非 Mock：

- 创建两个不同尺寸测试画板；只有当前画板启用 Fabric，另一个显示快照。
- 改变 Excalidraw 缩放和平移，验证逻辑坐标不变。
- 真实鼠标拖动图片，验证移动距离换算正确。
- 从抽屉通过 HTML drag/drop 拖入文字，验证落点坐标。
- 切换画板，验证各自对象归属。
- 保存两个画板、刷新、再序列化保存，验证坐标不漂移。
- 在画板上滚轮缩放，检查尺寸改变、文档坐标不变。
- 检查浏览器未捕获异常。

命令：设置 LOOMIC_E2E_EXTERNAL_STACK=true、LOOMIC_E2E_BASE_URL=http://localhost:3010 后运行 `pnpm --filter @loomic/web exec playwright test e2e/inline-artboard-probe.spec.ts`。完整单条浏览器场景通过。另运行 Web TypeScript 检查。

## 发现的限制与决策

1. 叠加编辑层必须有隔离的 stacking context，否则可能被 Excalidraw 覆盖并抢走鼠标事件。
2. 新建对象的 Fabric 7 中心原点与持久化左上角坐标不能混用。初版实验在重新加载后出现半宽/半高偏移；在隔离验证页明确采用左上角默认原点后通过。正式方案应显式设定各对象原点并审计历史文档，不应直接推广修改全局默认值。
3. SVG 原文与图片 URL 不能混用。本实验用 SVG data URL 验证图片路径，正式资源仍应按 image/svg 分类加载。
4. 目前只验证平移、等比缩放及两个未旋转画板。不代表旋转画板、跨画板移动、嵌套分组和复杂模板已经通过。
5. 本地草稿不是生产服务端持久化验证。本轮未验证并发 Agent 修改、版本冲突、断线恢复和真实资源目录。
6. 原型只有最小资源按钮和图层选择，没有完成共享快捷键、撤销、画板移动和原位尺寸修改。不能作为正式入口直接交付。
