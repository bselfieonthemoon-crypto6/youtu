# 设计画板用户指南

## 创建与编辑

1. 打开项目画布，在底部工具栏图片图标旁点击“设计画板”。
2. 选择预设尺寸或输入宽高（px）创建。画布上缩放节点只改变显示大小，不改变导出尺寸。
3. 双击设计预览进入编辑器。可添加文字、形状、图片、SVG、模板和工作区素材。
4. 使用属性面板调整文字、颜色、描边、阴影、裁剪、蒙版和滤镜；使用图层面板改变顺序、锁定、组合与对齐。
5. 修改会自动保存。关闭编辑器后，预览异步更新。

如果显示“本地修改尚未保存”，内容仍保留在当前页面；恢复网络后点击重试。多人同时编辑发生冲突时，系统不会静默覆盖，可重试或明确放弃本地修改并加载服务器版本。

## 模板和资源

- 平台资源由管理员审核发布；工作区资源只对有权限的成员可见。
- 从模板创建会生成独立设计，之后修改不会改变原模板。
- 带变量的模板会先显示替换预览，再确认应用。缺失图片或字体时系统会阻止错误应用并说明原因。
- 字体加载失败不会用错误字体悄悄导出；请替换字体或联系管理员恢复资源。

## Agent 操作

在对话中明确指定设计名称或选中的设计，可让 Agent 查看结构、修改对象、搜索资源、套用模板、导出或生成图片并插入设计。删除、覆盖整个场景、模板替换和可能扣费的生成仍受确认与权限限制。Agent 与人工编辑共用同一版本历史，重复任务不会重复插图。

## 图片工具

- 去背景：通过本地部署的 FeyNoBG 生成透明主体。
- 框选主体：框选目标后识别主体并生成结果，可再经过背景移除清理边缘。
- 透明擦除：本地直接把涂抹区域变透明，不生成新细节。
- 智能擦除：把遮罩交给图片模型补全背景，属于可能改变画面的生成任务；适合移除物体，不适合要求逐像素透明的场景。
- 高清、图层拆分等模型任务会显示进度和失败状态；原图不会被覆盖，结果作为新节点追加。

## 导出与删除

- PNG、JPEG 和透明 PNG 可在浏览器导出；超过浏览器像素预算时自动使用后台任务。
- 透明 PNG 会保留透明背景，JPEG 不支持透明。
- 删除无限画布中的设计节点会持久化为删除状态，刷新后不会重新出现。误删后的可恢复期由产品的恢复入口处理；不要依赖浏览器返回键恢复。

遇到资源 404、生成失败或字体缺失时，根据节点/面板提示重试或替换资源；反复失败时保留项目、设计名称和任务时间交给管理员排查，不要发送 API Key 或签名下载地址。
