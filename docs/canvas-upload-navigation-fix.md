# 上传图片后离开画布的保存保护

修复：菜单返回主页/项目库前等待图片读取与解码、活动画板保存、无限画布完整保存；任一步失败保持当前页面并提示。不依赖卸载后的 best-effort 请求。画布未初始化完成时禁用菜单导入；原生 Excalidraw 的 pendingImageElementId 尚未放置时拒绝离开，防止将未完成插入误当成已保存图片。

没有恢复或修改用户原画布中已有的删除标记。旧记录为何被删除仍不能仅凭最终数据确认。

验证：`apps/web/e2e/canvas-upload-navigation.spec.ts` 在独立本地项目中通过：

- 生成大于 64 KiB 的 PNG，经真实文件输入导入。
- 模拟保存接口 503，点击主页留在画布并显示错误。
- 恢复接口后返回主页，数据库存在活图片及文件记录；重新进入与刷新后仍存在。
- 工具栏原生图片插入：测试提供 Chromium 文件选择器返回值，后续使用真实插入逻辑；待放置时阻止离开，放置后保存得到两个活图片节点。

页面/保存策略单元测试 8 项通过。范围是应用内菜单导航，不承诺浏览器被强制关闭、断电或大体积 keepalive 请求的可靠持久化。
