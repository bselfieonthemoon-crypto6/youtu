状态：本轮目标场景修复与本地真实页面验收完成；通过与未覆盖范围见下，不代表所有自然语言或所有生产异常均已验证。

## 原则和来源

使用 OpenAI Docs 技能核对了官方说明：

- https://developers.openai.com/api/docs/guides/agent-builder-safety ：结构化枚举/字段、清晰行为示例、评测；不可信内容不能直接决定工具执行。
- https://developers.openai.com/api/docs/guides/function-calling ：严格工具参数 schema，不等于自然语言必须使用固定口令。

官方没有提供中文错别字确认词表。项目实现采用有界上下文语义分类，保留 owner/session/canvas/run/message/proposal 与幂等校验。不能将“确定/缺定/却定”在所有语境下都当作生图授权。

## 最终验收矩阵

| 场景 | 本轮结果 |
| --- | --- |
| 待生成方案后错字确认 | 真实页面成功生成 |
