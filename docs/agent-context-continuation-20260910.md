# 自动上下文整理与接续（2026-09-10）

## 本轮改动

- 不再固定保留本轮用户消息之后的全部工具过程。保留用户原话、系统约束、最新交换和未完成工具调用；更早的已完成调用及结果成对进入摘要。
- 只投影模型输入，不删除原始图状态或检查点。摘要不提供执行授权；原有成员、任务版本、历史来源及提交冲突校验继续执行。
- 摘要空正文或输出截断时自动拆小失败分块再试。最多三个初始块、九次总摘要调用；不重跑父任务或工具，不接受截断 JSON。来源伪造仍拒绝。
- 摘要版本更新为 v2，避免复用旧策略快照。
- 压缩中间件移动到自定义中间件列表末尾，先完成意图、工具及提示词组装，再计算整个请求；不删减权限规则。
