# 对话生图链路修复与验证（2026-09-07）

## 本次修复

- 增加 `list_designs`：按当前认证用户、工作区和无限画布读取真实设计节点，返回名称、ID、尺寸和修订号。多画板时提示选择，不编造目标。
- 原生设计图片在方案创建前、确认执行前均检查设计访问权限、工作区、所属画布及修订号。不合法目标不会创建提案或提交生图；全零 ID 明确拒绝。
- 用户明确要求原生设计但工具遗漏 target 时拒绝回落到无限画布。
- 方案准备显示“尚未生成”，不显示实际生成的占位卡；确认后才走生成任务。
- 等待超时返回 `processing` 和原 jobId，保留继续等待入口，而不是把仍在后台执行的任务报告为生成失败。
- 图片队列不再等待历史恢复扫描。恢复扫描单实例异步运行，慢扫描不阻塞新任务消费，不启动重叠扫描。
