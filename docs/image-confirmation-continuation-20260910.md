# 图片确认衔接

## 问题

会话先由模型口头描述设计方案，没有调用工具冻结方案。用户明确确认后，`get_image_proposal` 返回 `no_proposal`；随后 `generate_image` 保存方案，又无条件要求确认，造成重复确认。

## 验收边界

- 优先先保存方案，再展示方案并询问确认。
- 已有冻结方案：明确确认仍走原确认入口，不重新改写方案。
- 尚无冻结方案：本轮明确生成授权可衔接补建方案和原确认工具，不再重复询问。
- 普通“好的”、否定、修改要求不自动授权。
- 指定方案的产品确认不能被套用到另一个新方案。
- 新增透明前景处理等费用披露仍需确认。
- 同一授权轮的重复或并发工具调用不能提交多份任务。
- 继续沿用会话归属、来源、目标、有效期、冻结输入和幂等校验。

本次验收不调用收费模型；测试通过不等同于已完成真实模型端到端验收。
