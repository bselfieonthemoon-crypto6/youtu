## 修复的真实缺陷

1. 普通用户画板修改重试，在查询幂等记录之前就重新应用命令，导致重复 `object.add` 返回 400 “already exists”。现在旧版本请求先核验持久化回执（父版本、命令、操作人及操作类型），再交原数据库 RPC 做权限检查和幂等返回。未修改 Agent 的执行路径。
2. 模板引用查询读取不存在的 `design_documents.source_template_id` 列，实际返回 500。模板实例化是独立场景快照，没有这个持续引用关系；移除无效查询，保留目录可见性校验，返回正确空引用集。
