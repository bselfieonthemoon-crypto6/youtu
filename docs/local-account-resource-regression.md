测试入口：`scripts/test-local-account-resources.mjs`，仅允许 Supabase `http://127.0.0.1:54421`，HTTP API 固定 `http://127.0.0.1:3002`。每次新建两个独立账号与工作区；不操作原有用户或画布。测试账号及已归档测试项目保留用于排查，不输出密码、令牌或签名地址。

运行方式（项目根目录）：

机器结果：`artifacts/local-replica-20260907/account-resource-results.json`。以最近一次结果为准。

2026-09-07 最终回归：重启加载修复的本地 API 后，13 组真实集成测试全部通过（退出码 0），包括合法上传删除成功及删除后资源 URL 返回 404。使用的是新建独立测试账号，不是原有用户数据。

## 真实接口覆盖

- 注册、错误密码拒绝、密码登录、刷新会话、初始化独立工作区。
- 昵称修改及空昵称拒绝；工作区设置读取、保存、持久化及无效参数拒绝。
- 项目创建、改名、列表与详情持久化、归档；其他工作区读取/改名/删除被拒绝。
- 项目缩略图上传、签名地址下载、列表缩略图返回。
- 会话创建、改名、消息写入与读取、其他账号消息为空、其他账号改名/删除被拒绝、合法删除后列表消失。
- PNG 上传、签名下载字节一致、稳定 content 下载、preview 读取、跨工作区读取/删除保护、合法删除及删除后 URL 获取失败。
- 不支持 MIME 与含 script 的 SVG 拒绝。
- 品牌套件创建、更新、颜色资源增改删、复制、Logo 文件上传与下载、套件删除、跨账号隔离。
- 成员添加、角色更新、移除；工作区 owner 不能被降级或删除。
- 本地恢复令牌验证、重置密码后登录、退出后刷新令牌失效。

## 修复

1. 项目更新原本检查 `count === 0`，但未请求计数，因此 RLS 拒绝更新后仍返回成功。更新请求现要求精确计数并排除已归档项目，零行返回 404。
2. 会话改名和删除缺少影响行数检查，原本不存在/不可访问的会话也会返回成功。现请求精确计数，零行返回 404。
3. 上传删除的 legacy RPC 包装器解构调用 `client.rpc`，丢失 Supabase 对象的 `this`，合法删除会抛异常并返回 500。改为保留接收者的 `rpc.call(client, ...)`。

新增 5 项单元回归覆盖计数与 RPC 接收者；连同既有上传 content、成员路由测试共 11 项通过。

## 覆盖边界

以上为真实 HTTP/Auth/Storage 联调，不是完整浏览器逐按钮测试。恢复密码通过本地管理端生成测试恢复令牌，不包含邮件投递和找回密码页面。没有通过等待真实过期来验证自动刷新，也没有大文件压力、并发同名上传、所有图片格式或资源被引用时删除阻止的真实联调。视频和支付订阅明确排除。成员测试不包含第三方邮箱邀请投递。
