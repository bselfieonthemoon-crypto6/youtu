# 主体框选、保留/删除笔刷与确认预览

## 范围

在无限画布现有「去除背景」「框选抠图」入口接入非破坏性抠图编辑器。不更换默认模型、不改 Agent 生图、图层拆分或计费协议。

使用步骤：选中图片 → 去除背景 → 可选框选主体 → 自动去背景/识别框选主体 → 保留与删除笔刷修正 → 确认并放入画布。

「框选抠图」原入口先在画布框选，再将选区带入同一个编辑器。左侧显示原图和框选，右侧展示结果。笔刷粗细、圆形光标、撤销重做（含 Ctrl/Cmd+Z、Shift+Z）、辅助原图和透明/白/黑/蓝预览底色可用。

## 数据与安全边界

- 读取既有原分辨率图片处理链，保留已裁剪/翻转图片的实际像素。
- 模型任务明确 `target: null`，不传 canvas_id/session_id。预览完成不自动插入画布或聊天。
- 框选结果按模型返回的裁切偏移复原到完整原图坐标，拒绝越界或尺寸错误结果。
- 模型输出作为初始 alpha；保留笔刷恢复原图像素，删除笔刷擦成透明。模型的软透明边缘不二值化。
- 背景底色与辅助原图仅用于显示，不参与导出。
- 确认时导出原像素尺寸透明 PNG，先上传持久化素材，再插入新节点并等待画布保存。原图不删除。
- 同一确认结果保存失败后使用相同 PNG、素材和节点身份重试，避免重复插入。
- 全透明结果禁止确认，但仍允许保留笔刷恢复。
- 关闭预览会丢弃当前未确认的笔刷草稿；已经提交的模型任务可能继续完成，但不会自动插图。没有承诺取消后台计算，也没有实现跨刷新草稿恢复。
- 超过 3200 万像素的图片会提示先缩小，避免多画布合成造成过高内存占用。
- 笔刷是手动像素修正，不是新的智能分割模型。不能保证复杂毛发、透明物体一次自动识别准确。

## 实现位置

- `apps/web/src/components/canvas/image-matting-editor.tsx`：编辑交互、预览、笔刷、确认与失败恢复。
- `apps/web/src/lib/matting-editor.ts`：坐标、alpha 合成、笔刷和尺寸校验。
- `apps/web/src/components/canvas-tool-menu.tsx`：工具入口、独立预览任务、持久化 PNG 和新节点。
- `apps/web/src/components/canvas-editor.tsx`：复用立即保存函数，供导航和抠图确认共同调用。

## 验证

在本地副本 `localhost:3020` / `127.0.0.1:3002` 的独立回归项目验证，没有修改用户原画布。

- 前端类型检查通过。
- 32 项相关前端测试通过：笔刷几何、合成、越界保护、显式确认、预览失败、双提交、关闭后晚到结果、保存重试、全透明保护、原图读取、存储下载、缩放遮罩。
- 9 项后台画布任务收尾测试通过，新增独立抠图预览不插入的回归断言。
- 浏览器原工具回归：2 种图片来源，覆盖去背景、框选、拆层、透明擦除、下载、裁剪再处理；原图像素保持。
- 浏览器上传/立即回首页/保存失败阻止离开回归通过。
- 浏览器笔刷验收使用真实 API、队列、worker、上传和存储；仅将初始分割替换成确定性的本地透明擦除，逐像素验证保留/删除、快捷键与按钮撤销重做、预览不插图、503 保存失败重试仅上传一次、透明 PNG 持久化和刷新。
- 另有未替换算法的真实模型测试，调用自动去背景及框选抠图；检查主体中心保留、选区外透明、关闭不会插图。软 alpha 使用范围断言，不要求主体中心严格等于 255。
