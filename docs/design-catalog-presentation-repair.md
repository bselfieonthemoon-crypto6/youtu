## 已修复

- 文字预设导入保留 `paintFirst`、`splitByGrapheme`，共享契约与数据库校验同步支持。按原资源对象 ID 补回 120 条文字预设/模板数据，非按名称猜测。
- 浏览器文字渲染支持描边顺序、中文逐字换行；服务端 SVG 预览支持相同的描边顺序。
- 插入文字前加载真实字体；失败明确提示而非插入替代字体。字体加载后清除 Fabric 字宽缓存；字体缓存按文件、名称、字重、字形区分；避免普通场景更新中断字体加载效果。
- 普通无变量模板原先错误进入变量替换，导致零命令、按钮禁用。现在明确提示整套替换内容和尺寸，经确认后应用，进入原有保存/撤销历史。
- 模板弹窗通过 Portal 在画板之上显示，修复可见但被 canvas 拦截点击的问题。
- 18 条具有 `Local QA / Test fixture / Local test only` 且名称匹配回归测试记录的资源已软删除。未删除底层文件；完整记录备份在 ignored artifacts/local-replica-20260907/catalog-repair-backup-*.json。修复脚本带本地 URL/数据库保护，可 dry-run。
