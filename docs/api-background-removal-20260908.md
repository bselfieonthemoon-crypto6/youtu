# 去除背景切换为 GPT Image 2 API

## 行为

- 无限画布和画板图片工具中的 remove_background 均通过现有工作区 API 配置执行，不再进入 BiRefNet/FeyNoBG 本地进程。
- 服务端从已启用、连接测试成功的目录精确选择 upstream_model_id = gpt-image-2，绑定任务配置快照。忽略客户端传来的 all、vip 或历史 local:feynobg；找不到精确模型则返回 409，不降级。
- 使用 /v1/images/edits，原图作为输入，background=transparent、output_format=png、n=1；保留原主体的提示不等于像素级无损抠图。
- 实际输出必须是 PNG，具有 alpha，并同时包含可见和非完全不透明像素。无 alpha、全不透明或全透明结果不进入画布；无效透明结果不自动重复付费调用。
- API 尺寸遵守 16 倍数、最大 3:1、最低像素数；最终以 contain 恢复原图像素尺寸，不拉伸、不裁掉主体。超长宽比例的图片可能有留白。
- 沿用已有持久任务、原图读取、权限、扣费/退款、画布落图及画板对象版本冲突处理。无限画布仍在原图旁新增；画板内部仍使用既有目标图层替换逻辑。
- 成功透明结果使用确定性资产 ID 保存；任务在保存之后重试会读取已有结果，避免再次请求模型。提供商返回到首次持久化之前的故障窗口仍可能产生额外请求，不声称外部 API exactly-once。

## 范围

本次调整的是显式“去除背景”操作。框选主体、图层拆分、擦除，以及 Agent 生图后原有的自动前景后处理策略未切换，不额外引入第二次付费 API 调用。未删除本地模型文件，普通对话生图的默认模型也未更换。
