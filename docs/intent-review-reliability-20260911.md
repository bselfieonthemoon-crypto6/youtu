## 结构性处理

- 只读审核负责其自身的有界恢复；执行工具不承担重试审核的职责。
- 内部失败、用户歧义和真实权限拒绝保留不同机器码。内部故障不能要求用户重新描述需求。
- 内部恢复耗尽后，同轮同工具不再次调用审核模型；图片流程直接生成真实失败回执，不再让主模型重复提交或声称已保存。
- 新用户轮次可以重试；不跨轮缓存失败，不恢复无人值守。
- 原始请求、参考图、作用对象、版本、所有权及付费确认仍独立核验。审核格式修复不等于放行。
- 没有通过“出错直接执行”或“去掉原图参数”绕过安全边界。
- 简单独立图片草稿使用精简审核提示，明确草稿保存与收费确认不同；有参考图或已有对象的操作仍走完整核对。
- 输出预算由固定 1500 调整为不超过 3000、且受原模型输出上限和已验证 profile 约束；不盲改供应商思考参数。
- 内部格式/调用异常最多一次恢复，共享 60 秒总截止时间。有效语义拒绝、证据不匹配、工具调用越界和用户取消均不重试。只有完整 fenced JSON 可规范化，不截取混合解释中的片段来放行。
