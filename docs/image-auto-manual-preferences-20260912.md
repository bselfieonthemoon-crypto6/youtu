## 根因与修改

- 续写/纠正入口可能重放旧任务的图片偏好与模型 mentions：改为当前 UI 偏好和当前消息引用；编辑重发保留被编辑消息的显式引用。
- 工具 model enum 在执行门禁前拒绝历史失效 ID：在当前工作区可用目录及本轮手动/@约束下，确定性归一化后再审核，工具内二次校验。手动失效/空选/冲突不会静默切 Auto。
- 空参考图下孤立 `sourceUsage=reference` 去除；不补造图片、不删除真实来源，用户确实要求参考时仍须通过来源审核。
- 当前选定比例、当前文字尺寸冲突时澄清；有效既有比例保留，Auto 默认只补缺省；Logo 1:1、明确竖版/手机海报 9:16、官网横幅 16:9。普通用途不明的独立图不盲目按正方形生成。
- 时间、多个/否定比例不作为单个明确尺寸；短回复“可以”不能把已有 16:9 无条件改回 Logo 默认 1:1。
- 测试驱动新增 `--image-mode=auto`，并断言实际 wire preference 与测试选择一致，不沿用以前脚本固定 manual 的设置。
