# 本地悬停主体选区

最新默认入口已改为 LLM 定位 + SAM 分割，见 [默认 LLM 流程](subject-vision-default-20260908.md)。以下记录先前本地自动去背景阶段及悬停实现。

按用户补充要求，交互改为鼠标悬停识别整块主体并显示红色蒙版，不显示提示点。点击红色候选区后，才加入右侧保留结果；可以连续添加主体、减去区域、清空并重新选择，再用保留/删除笔刷修正。最终确认保存透明 PNG，保留原图。

后续更新：打开预览窗口即自动运行一次本地去背景，生成初始保留区域（左侧红色蒙版）和右侧透明结果，无需先移动鼠标或点击扫描。仍停留在悬停选择模式，可添加/减去其他主体或切换笔刷。只有“确认并放入画布”才写入画布。每次打开只自动提交一次，兼容 Strict Mode；失败不会循环重试，可手动点击“自动去背景”重试。

## 本地方案

- 复用已安装的 SAM 2.1 Hiera Tiny，不下载 SAM 3，不接外部推理 API。
- 服务内部将鼠标位置转换为 SAM 的前景提示；这只是模型内部输入，不是需要用户手工放置的点。
- 新增鉴权接口 `POST /api/images/subject-preview`，校验画布访问权限、原图格式和坐标。仅接收内联图片，不抓取外部 URL。
- 悬停接口不创建 background_jobs、不上传临时素材、不写画布、不扣生图积分。打开窗口的初始自动识别复用本地去背景任务（target 为 null，不绑定画布），会保存临时任务结果，但不自动添加画布节点。确认保存时才上传最终修正图片并持久化画布。
- 服务端限制一个并发推理，忙时返回 429；没有无限排队。
- 浏览器悬停 350ms 后请求，单会话最多一个在途请求，移动期间仅保留最新位置。过时响应不能成为当前位置的候选。
- 浏览器缓存最近 4 个选区，鼠标位置按 64×64 网格归并。模型端按原图 RGB 内容哈希缓存一份图像特征；重复处理同图仅重新运行提示解码器。
- 红色蒙版不参与导出。选区 alpha 与原图 alpha 仅相交一次，避免半透明原图被重复乘透明度。
- 原画板编辑器旧矩形接口保留兼容；无限画布图片工具入口改为“主体选取”。

## 体验边界

- 首次加载模型/扫描原图需要等待，CPU 不保证实时。缓存命中较快，不同图片交替会重新编码。
- 悬停红色包含当前候选和已保留区域；右侧显示初始自动识别结果及后续明确保留的区域，鼠标经过的候选不会直接加入右侧结果。
- 不是 Photoshop 等产品的同等精度保证。模型可能选到背景、漏字或边缘不够细，需移动到主体内部换候选、减去区域或用笔刷修正。
- 关闭窗口不保存未确认草稿；在途本地计算可能继续完成，但不能写入画布。
- 服务无推理 API 费用，但使用本机 CPU、内存与电力。

## 验证

- 前后端 TypeScript 检查通过。
- 前端 17 项测试：既有合成/保存恢复测试，加悬停识别、点击前禁止确认、缓存命中、移出原图丢弃晚到结果。
- 后端 16 项相关测试：新接口身份/画布权限、输入校验、并发限制、失败释放容量、临时返回；既有服务与任务收尾测试。
- Python 2 项测试：坐标、尺寸、蒙版与原透明度职责、无效提示不加载模型。
- 浏览器回归独立项目：真实 SAM 本地悬停识别红色蒙版、点击保留，未创建额外生图任务；确定性测试验证选区合成、笔刷、失败重试、PNG 存储和刷新；原图工具与导航 3 项回归通过。

真实模型测试输入为简单合成主体，不等于所有 Logo、海报、毛发都已质量验收。未修改用户原画布内容。

自动识别入口更新验证：前端类型检查及 17 项单元测试通过；Strict Mode 与回调重渲染只提交一次，失败允许手动重试，关闭不应用晚到结果。浏览器真实模型测试验证无鼠标操作时两侧已有主体预览，另有笔刷/持久化/保存重试及两项原图工具回归通过。首次确定性回归因后台任务超过 40 秒等待失败，任务随后成功；将该测试等待限额调为 90 秒后重跑通过。产物位于 `apps/web/test-results/matting-auto-entry`、`matting-auto-entry-retry`、`matting-auto-toolbar`。
