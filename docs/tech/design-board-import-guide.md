# 设计资源导入指南

设计资源后台支持三种入口：ZIP 上传、内联 JSON manifest、受限服务器目录。入口统一创建导入 Job，由 Worker 校验、解析、上传并生成逐项报告。

## 支持的内容

- 分类与标签；
- 图片和 SVG 素材；
- 字体 family/face；
- 文字模板；
- 设计模板及其图片、字体依赖。

混合包按依赖顺序处理。模板不能引用不存在、跨工作区、未发布或不匹配的资源；默认图片和字体变量同样参与依赖校验。

## 推荐流程

1. 在管理后台进入“设计资源”，选择 ZIP/JSON/服务器目录。
2. 填写来源、作者、许可证和原始地址。来源不明确的条目保持 `pending_review`。
3. 提交后查看 Job 和逐项 report；失败条目修正后再重试。
4. 在预览中检查字体、透明度、模板尺寸和依赖替换。
5. 管理员审核后发布。未发布内容不会出现在普通用户或 Agent 搜索结果中。

## 安全限制

- 不接受绝对路径、`..`、符号链接逃逸或解压后越过临时目录的文件。
- ZIP/tar/远端内容受下载大小、条目数、展开大小、MIME 和重定向限制。
- URL 抓取拒绝本机、私网、metadata 地址、混合 DNS 和跳转到私网。
- 服务器目录只能位于 `LOOMIC_DESIGN_IMPORT_ROOT` 之下，并要求 Web 端显式开启入口。
- 任何导入项在授权材料不完整时不能发布为平台公共资源。

## 运维与重试

导入任务使用带 claim token 的租约；旧 Worker 即使迟到也不能提交新 Worker 已接管的结果。仅 `failed` 或 `canceled` 任务允许重试，安全校验失败应先修正源数据。不要直接在数据库修改任务为成功。

导入成功后应抽查：资源列表可搜索、预览可签名、模板依赖完整、字体可加载、普通用户看不到 `pending_review` 内容，以及删除源包不会影响已导入的私有 Storage 对象。
