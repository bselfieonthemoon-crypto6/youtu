## 修改

1. chat-service：使用用户 RLS 检查目标画布/会话，无权与不存在统一 404；底层故障保留 500，写入阶段 RLS 竞态亦返回 404。消息幂等回读保留。
2. credit-service：只有明确的 23505/credit_job_already_refunded 才查回执，并匹配工作区、用户、任务、退款类型和正金额；返回原退款 ID。其他错误不吞掉。
3. CurrentConversationIntent：系统消息只保留固定规则；当前用户原话留在用户消息，不再复制到高优先级消息。真实图集成测试断言最终请求角色边界。
4. 参考分析：独立 reference_observation 路径，只接收本批像素、资产 ID 和数量，不再接收全任务验收简报；主 Agent 汇总各批事实。第一次仅添加范围提示的真实复测仍误报其他批次缺失，故未采用该版本作为最终修复。成图验收保持原路径，真实不确定信息仍保留。
