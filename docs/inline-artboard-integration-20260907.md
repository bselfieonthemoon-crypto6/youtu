# 原位画板第二阶段：受控接入

## 开启与回退

- 在已有画布 URL 上增加 `&inlineArtboard=1`，双击画板进入原位编辑。
- 不带该参数时保持原来的编辑入口；对话切换保留开关。
- 原位工具栏可先保存再切回完整编辑器，使用全部编辑和导出功能。
- 分组、旋转对象及旋转画板仍回退原编辑器。这是兼容性门槛，不是已完成这些对象的迁移。

## 已接入

- 复用 DesignEditorSession 的真实文档 API、版本、保存历史、撤销重做和 design.sync 消息处理。
- 从正式资源目录读取素材、模板、文字样式和字体；原位界面提供资源抽屉、图层及属性面板。
- 素材支持拖入：使用授权资源内容接口，保留 resourceId/assetObjectId，换算画板坐标，按画板大小缩放素材。模板、字体及文字样式仍通过原有点击操作应用。
- 异步素材拖入任务纳入保存等待，切换画板/发送对话前先保存。冲突不静默丢弃本地修改。
- 当前画板 ID 通过共享协议、WebSocket 和 Agent runtime 传递；生图工具拒绝遗漏或指向其他画板的新方案。
- 已冻结的图片确认方案仍使用原目标；界面明确提示。取消确认不依赖当前画板成功保存。
- Fabric 的左上角原点仅在原位实例启用，不修改全局默认值；旧编辑器行为不变。

## 验证证据

- Web 完整测试：346 项通过。
- Server src 完整测试：529 项通过。
- Shared 测试：109 项通过。
- 新增覆盖：原位保存失败不退出、原位撤销/资源槽、冲突恢复、Agent 发送前保存、保存失败不提交、WebSocket 目标透传、生图目标缺失拦截。
- Chrome 技术原型：真实鼠标拖动、缩放平移、资源拖入、切换画板和本地刷新。
- Chrome 真实数据库联调：新建隔离项目/设计文档，添加文字，保存、撤销、重做、刷新；从正式素材目录拖入素材，验证引用、最终落点和再次刷新。
- 联调曾发现切换对话丢失开关，已修复；测试等待最终移动保存，而不是把插入成功误判为整次拖放完成。

实时联调需要显式设置 LOOMIC_INLINE_LIVE_USER_ID，并且只创建测试项目，不改现有画布；测试 trace/video 关闭，不保存认证信息到仓库。不自动清理测试项目，便于用户复查。

最终两条 Chrome 场景通过（58.6 秒）。最后一次真实联调项目：`50f736a6-85ea-4b18-946e-9c9ef2689921`，画布：`aa990d3b-1c04-4cb4-b3f7-93eef1d40356`，设计：`f748a4f4-a52b-4090-8e00-7b79d5750fb4`。截图：`apps/web/test-results/inline-artboard-live.png`。浏览器联调端口为 3010，API 为 3001；未启动生成 worker。

## 尚未作为正式验收项

- 本次没有调用真实模型完成新界面下的生图；目标路由/保存与拦截测试不能替代模型到 worker 到画板的全链路验收。
- 未完成复杂分组和旋转迁移、多画板跨对象拖动、统一所有快捷键及交互手势。
- 未进行千图压力、多客户端长时间并发和断网耐久测试。
- 本阶段是开关后的集成版本，不是默认切换或最终视觉设计。真实资源和保存联调通过不等于整个产品零缺陷。
