# 实时连接边界修复与复测

## 范围

修复上一轮确认的成员撤销后旧订阅继续收消息、多个 API 实例竞争同一 outbox 导致其他实例漏通知两项问题。业务实现由 gpt-5.6-sol / high 子代理完成，主控负责 SQL 审查、迁移和真实集成复测。没有调用第三方模型或生图，没有操作用户当前画布。

## 实现

- 迁移 `20260911000013_durable_realtime_fanout.sql`：持久化事件日志和每 API 实例独立游标；设计写入、成员删除/角色变更与通知在同一事务落库。
- 事件写入及消费者注册共用事务 advisory lock，避免先分配 ID、后提交事务被游标跳过。
- 每实例按序投递并确认游标；失败不前移。旧 outbox 默认不再直接广播，避免双路径重复通知。
- 删除成员及角色变更后本机立即使连接失效；其他实例通过持久化事件失效。发送画布数据/RPC及敏感直达响应前重验数据库权限，失败关闭连接。
- 异步权限检查后复核连接代次和画布绑定；画布流式事件串行发送，避免检查耗时导致文字乱序。
