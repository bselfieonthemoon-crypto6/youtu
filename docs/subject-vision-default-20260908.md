# 抠图预览默认 LLM 识别

已从独立实验接入无限画布的“去除背景”和“主体选取”共用窗口；不改变其他生图、橡皮、图层拆分和画板 Agent 流程。

## 当前流程

1. 打开窗口，自动且仅一次发送 `/api/images/subject-preview`，`mode=auto`。
2. 服务验证身份及画布权限，校验图片大小，规范原图方向。
3. `deepseek-v4-flash-vision-exp` 经项目现有 APIYI 配置识别主体，返回归一化框和正/负点。严格验证模型输出，不直接执行模型文本。在线调用设 90 秒超时、无自动重试。
4. 本地 SAM 2.1 Hiera Tiny 使用框与点联合生成全尺寸蒙版。左侧显示红色，右侧使用原图像素与蒙版合成透明结果。
5. 鼠标悬停仅调用同接口本地分支，不调用 LLM。点击添加红色候选；切换“从保留区域减去”后点击减去候选。仅悬停不会提交修改。
6. 保留/删除笔刷可继续修正；确认时上传最终 PNG 并持久化画布，原图保留，保存失败沿用同一上传和节点重试。

## 失败与边界

- 初始 LLM/SAM 失败会明确报错，不静默切回旧去背景模型；可以显式重试 LLM 或悬停手选。
- 自动识别和手动重试可能产生供应商 API 费用，页面已说明；悬停不产生额外 LLM 调用。
- 初始预览不再创建 background_jobs、临时资产或画布节点，关闭窗口不保存；已发送的推理可能继续完成，不能承诺关闭即取消供应商计费。
- 当前单 API 实例限制一个识别请求，繁忙返回 429；未做多实例全局限流。
- 首次本地模型加载仍可能较慢。该变更改善语义选择，不保证 Logo 描边、毛发或半透明边缘完全准确。
- 主体判断采用默认语义提示，本轮没有增加用户文字描述输入框。
