# 对话优先：最小执行可靠性

本需求替代此前无人值守、自主后台续跑和自动验收循环的产品要求。历史验收文档仅作为问题记录，不再作为待实现需求。

## 保留范围

- 用户主动对话驱动操作；保存原始对话、当前需求、最新纠正、相关图片和未完成事项，支持摘要压缩与原文回查。
- Skills 和设计工具按需加载；一次请求内可执行必要的多个步骤。
- 普通图片任务保留排队、完成、失败、取消、状态查询、刷新恢复和防重复提交。已提交任务可正常完成，不等同于自主发起新任务。
- 确认对应已保存方案的确定版本，引用明确原图和目标；不得重新猜参数、重复收费或丢弃约束绕过错误。
- 多交付物保留轻量清单，由用户对话推进。用户可以明确请求检查图片。

## 移除范围

- 自动执行开关、会话自动执行授权、无人值守预算与后台自主循环。
- 出图后自动追加模型调用、自动视觉验收、自动改图和自动推进后续交付物。
- 无人值守签名、调度入口和自动跨画板执行授权。

## 数据与兼容

不删除历史对话、作品、资产或普通生成任务。历史自动化表停用其执行能力，不破坏共享记录。旧客户端不能通过遗留入口重新开启自动化。

## 验收

1. 新旧用户都没有自动执行入口，旧授权不触发后台模型调用。
2. 普通对话、生图提交、状态、取消与刷新恢复仍可用。
3. 多轮承接保留最新纠正；确认、部分确认、交付物与参考图不串联错位。
4. 明确失败停止，不重放终态任务、不重复收费。
5. 类型检查与定向测试通过；真实多轮验收单独记录，不能用单测代替。
