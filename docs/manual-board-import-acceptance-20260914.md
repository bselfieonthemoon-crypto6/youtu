# 手动将画布图片加入画板：实现与验收

日期：2026-09-14。范围仅限手动编辑，不涉及 Agent、生图渠道或视频。

## 交互

- 画板外：选中图片 → 添加到画板 → 选择目标。创建独立图片图层，等比适配居中，保留画布原图。支持新建画板后加入。
- 完全位于画板内：选中图片 → 加入此画板 → 选择目标。保留相对位置、大小、旋转；图层写入成功后才移除画布实例。
- 中心在画板内但图片超出边界：按钮路径提供复制并适配，避免静默裁掉原图。
- 拖入：选中图片后拖到目标画板；外部来源恢复原位置，并按落点添加副本。多个目标由用户选择。
- 成功提示提供撤销加入、编辑画板图层。原始素材引用与聊天结果不删除；图层编辑不反向同步画布原图。

## 可靠性

- 服务器从已保存画布解析素材引用，不接受客户端伪造素材 URL；检查权限、项目、来源与画板版本、锁定状态。
- 使用现有设计文档 CAS、素材引用和幂等机制，不增加数据库迁移。
- 未知请求结果保留完整请求和幂等键；明确 4xx 拒绝后允许下一次读取新状态再提交。
- 加入失败不移除原图；撤销转换先恢复原图，再删除导入图层。中断可能留下副本，但不主动丢失原图。
- 已继续编辑的图层不由快捷撤销强行删除。预览通过本地设计预览任务更新，不调用生图模型。
