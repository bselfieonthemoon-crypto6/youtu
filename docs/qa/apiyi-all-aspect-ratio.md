# GPT Image 2 All 比例传递修复

任务中 aspect_ratio 经执行器传给供应商适配器，但 gpt-image-2-all 分支不发送原生 size，之前也没有把比例附加到 prompt，导致约束在对外请求中丢失。

现在仅对该模型在请求边界统一追加输出画布比例和方向约束，覆盖 images.generate 和 images.edit；未指定时沿用 1:1 默认，非法比例在请求前拒绝。原提示保留，其他模型的原生尺寸逻辑不变。非标准比例不会用 1536×1024 预设替代。

15 项适配器与工作区模型映射测试通过，服务端类型检查通过。本次未额外请求付费生图，未修改旧图片。

限制：这是提示词约束，不是供应商对比例的硬性保证。既有执行器会读取真实像素尺寸，但尚未增加返回比例不符的产品警告或拦截；不得把尺寸读取等同于比例合格校验，也不要为比例偏差自动重试产生额外费用。
