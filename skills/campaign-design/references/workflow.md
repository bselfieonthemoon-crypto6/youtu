# 活动海报与宣传图：按需细则

美术方向分别考虑主视觉表达、配色角色、材质和文字密度；它们是可调整变量，不是必须填写的问卷。已有品牌资产优先。标题表达一个主张，细则承接证据，CTA 指向真实入口；二维码或链接素材缺失时不要造可扫码假码。

位图 prompt 必须逐字保留用户确定的标题、价格、日期与行动文案。可用英文描述画面，但不得因此翻译或改写应显示的中文文字。生成图片仍可能拼错字，只有实际结果可验收。用户要求多比例时分别调整焦点、裁切与行数，不将整图非等比拉伸，也不默认增做更多尺寸。

新图用 `generate_image`；已有海报修改或明确参考原图用 `edit_image.sourceAssetIds`、`sourceUsage=edit/reference`。来源须是当前可核验 UUID。工具不接受原生设计 target；也没有旧图片方案确认步骤。不同页/尺寸的任务状态逐项核对，processing 不等于完成。
