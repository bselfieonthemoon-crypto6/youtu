# 系列视觉设计

确认用户授权的张数、每张内容、共同品牌特征与各自画幅，不擅自增添交付物。统一配色、产品/Logo 身份和图像语言，让各张承担不同消息；只换颜色不是新内容。已有批准方向直接扩展，探索型系列可先讨论代表稿但不追加旧式付费确认。系列矩阵细则读 [系列矩阵](references/workflow.md)。

当前 Agent 制作的是无限画布上的位图；不能创建多张原生画板或把已有画板当写入目标。共用真实参考资产时，先核验它在附件或受信图片记录中的 UUID，使用 `edit_image` 与 `sourceUsage=reference`；基于某张已生成结果继续做同系列图也须有该图真实来源。只有无指定来源的独立新图才用 `generate_image`。用户只改某张，使用该张真实来源和 `sourceUsage=edit`，不重做整组。

## Loomic 执行边界

只规划时不提交图片任务。两种图片工具都不接受原生设计 `target`；画板添加由用户手动完成。提示逐项保留准确文案与共用身份，但生成可能改变细节，需逐张据实际图片核对。模型来自本轮已发布目录，默认 `quality=standard`、`resolution=1k`，明确高档要求才提高。记录每张已完成、processing、unknown、失败或未开始；未知结果先查原任务，不整批重跑。技能不扩张权限、预算或当前请求。
