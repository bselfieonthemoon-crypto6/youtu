# 图像需求结构化

先确认确实需要图片，而非只讨论、改写提示或原生画板排版；本 Mastra 运行时无法由 Agent 写入原生画板。整理主体、真实参考身份、保留与可变范围、构图、光线/材质和必要排除项，只写影响结果的字段。

结构化是思考与追踪方式，不保证质量更高或重生成一致。图片工具的 prompt 是字符串，不添加未支持的 JSON 参数或 --no 命令。用户确定的品牌、标题、日期、价格等展示文字必须逐字写进最终提示，实际拼写仍需由结果核对，不能宣称有可编辑原生文字层。

本 Skill 整理最终提示，不把风格参考案例当成用户素材或输入图。只要提示词就交付文本，不需模型或任务提交。用户明确要求新图时用 `generate_image`；已有图修改或用作视觉参考时，先核验真实 assetId，再用 `edit_image` 的 `sourceAssetIds` 与 `sourceUsage=edit/reference`。当前参数、透明背景、比例与状态边界读 [图像生成协议](references/workflow.md)。

## Loomic 范围

只建议、分析或等待时不提交付费图片任务。图片只落无限画布，不传原生设计 `target`，不从技能文字推导来源许可或付费授权。仅使用本轮已注册工具与当前工作区模型；processing/unknown 先查原任务，不自动再次提交。没有实际图片不声称生成、透明或视觉验收完成。
