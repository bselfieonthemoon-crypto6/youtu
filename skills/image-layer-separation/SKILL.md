# 图片分层与原生图层

先确认用户指的是已有画板中的真实对象，还是单张扁平图片。对象 ID、源资产与当前目标从实际工具读取，不把截图中看起来独立的元素当作已有图层。

对原生设计，inspect_design 与 get_design_objects 可以读取真实层级，再使用 manipulate_design 在用户指定范围内修改、分组或调整层序。保留字体和其他对象；单纯移动某一层不需要先拆图或重设计。

对扁平图片，选中原图使用图片工具栏的「图层拆分」。大模型流程按用户指定的 2–4 个元素分别生成透明 PNG，再移除这些元素、修补完整底图，默认 Low + 1K。元素名称应具体，例如“左侧蛇形角色”“右侧人物”“所有标题文字”“前景金币”。未选择的元素保留在底图；这不是自动发现所有潜在图层。界面提交一项拆分任务，但内部需要元素数量加一次背景生成，按总量计费。透明素材会按有效像素裁成小图，并记录相对位置，原图保持不变。

当前 Agent 的 generate_image/edit_image 工具没有直接 split_layers 操作。不要发送不存在的工具参数，也不要用一次普通生图冒充多层拆分；通过真实工具栏流程执行，不声称已从 PNG 恢复原始字体、遮挡内容或 PSD。大模型可能重绘细节，底图修补是推测；要求逐像素无损时应说明限制。

此技能仍为工具栏操作与验收指导，不会安装模型或服务。阅读 [分层验收与引擎边界](references/workflow.md) 检查真实结果。专用分层和旧本地处理属于独立入口，不应在失败时悄悄互相替代。

只要求建议或检查时不修改对象。执行仍受当前工具、画板目标锁、用户纠正、权限和费用确认约束；技能说明不增加这些权限。
