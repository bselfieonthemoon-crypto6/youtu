# 尺寸适配与交付

用户提供的是交付像素，不是模型必然能接受的尺寸参数。读取生成结果实际宽高，不因提示词写了尺寸就宣称精确。

## 构图路由

以下比例是设计启发式，不是工具能力边界。根据实际内容密度调整：

| 宽高比 r | 默认构图 |
|---|---|
| r ≥ 3.2 | 窄横条：一个短标题、一个主体头像/半身、可选 Logo 或简短按钮；按内容决定左右位置 |
| 1.45 ≤ r < 3.2 | 横幅：文案约占宽度 45–58%，主体约占 35–48%，保留间隙 |
| 0.85 ≤ r < 1.45 | 方/近方：顶部品牌或标题、中部主体、底部短信息；或主体偏右、左侧短标题 |
| 0.58 ≤ r < 0.85 | 竖海报：顶部标题，中间主体，下部利益点和按钮 |
| r < 0.58 | 长竖版：纵向故事场景，分层安排头部、主体和底部，不上下拉长角色 |

一般安全边距取短边的约 4–6%；320×70 一类小横条改为约 6–10 px，根据 Logo 和文字量校准。按最终显示尺寸看可读性，不按放大预览判断。文字行数、对齐和效果按 [字体与排版](typography.md) 决定，不沿用固定三行居中模板。文字过多先分行、减装饰、增加文案区；不要未经允许删改条款、金额或标题。确实放不下时请求精简文案或增大尺寸。

## 两种交付方式

### 整图生成

适用于常规比例、短文案、没有严格 Logo 一致性要求的视觉图。使用当前图像工具生成相应构图并查看实际结果。需要图像修改时使用图像编辑工具。用户接受近似尺寸时注明实际尺寸；要求精确像素时不能以近似替代。

### 生成素材 + 精确画布排版

适用于极窄横幅、多尺寸同一角色、精确品牌标识、逐字正确文案。先确认本地可用的排版和 PNG 导出方式，再生成缺少的无字背景/主体素材；用户已提供可用角色时直接复用，只有明确要求变体才重新生成。之后在 SVG/HTML Canvas 等原生画布内放入素材、用户原始 Logo 和可编辑文字，导出准确 W×H 的 PNG。技能本身提供工作流，不捆绑可用性未经验证的导出工具。

这是一个明确的程序化组合步骤。用户已要求精确合成或同意该步骤时执行；若当前图像工具规则要求编辑必须经图像工具，则先遵循当前规则，必要时向用户说明需要精确排版授权，不能绕过规则偷偷用 Python 修改图片。默认不把 raster 插画替换成 SVG 占位图。

Logo 使用原素材等比放置，保留品牌色和净空，不让生图模型重画以追求“像原图”。需要复用同一角色时生成一次可复用主体，不分别生成造成身份漂移。素材无有效透明通道时不要把白色背景或棋盘格当透明，也不要强行贴到背景上；通过图像工具获取正确素材。

整图等比 contain 仅在比例接近且边缘扩展可接受时使用；它不会自动完成重新排版。避免关键主体裁切、非等比拉伸、为了适配极端尺寸添加突兀大留白。原生 SVG 须内嵌素材或同时交付依赖，保证移动后可用；字体缺失时使用可用字体并检查字形。导出工具不存在时明确说明缺少 PNG 导出，不假称已交付。

## 离线与实图验收

- 调用前检查需求：尺寸列表、逐字文案、素材路径和角色、是否需要精确排版。
- 成品检查：实际像素、无裁切拉伸、Logo 完整、字符和数字准确、素材身份、装饰不遮挡文案；文字设计符合当前风格且满足用户对变化或套系一致性的要求。
- 多尺寸并排检查：同一套的角色/色板/字体气质一致，各比例独立构图；每尺寸一个文件。
- 未实际调用生成工具时，只能报告技能结构/方案验证，不能报告模型画质、品牌保真或实图尺寸测试成功。
