# Logo 与品牌标识

提取准确品牌名称、使用尺寸、已有标识资产和保留项。缺少决定标记身份的文字才询问；允许自由发挥时可合理默认。开放探索可比较轮廓与识别逻辑不同的方向；用户指定一版就深化，不强制概念投票。

本运行时交付的是位图图片，不是可编辑矢量母版。复杂曲线、单色变体或样机可以作为概念讨论，但不要宣称 SVG 路径、商标检索、注册可行性或实际 16/32px 检验已经完成。方法细节读 [标识方法](references/workflow.md)。

## Loomic 执行边界

只讨论或只要提示词时不调用付费图片工具。用户明确要求制作新图时，使用当前注册的 `generate_image`，在字符串 prompt 中逐字保留品牌文字；已有标识需要局部修改或作为视觉参考时，先从当前附件或受信图片记录取得真实 assetId，再用 `edit_image` 的 `sourceAssetIds` 与 `sourceUsage=edit` 或 `reference`。没有源图证据不猜 ID，也不以纯文字冒充参考图。

两种图片工具只交付无限画布，不传 `target`，不创建、修改或导出原生设计画板。原生画板可读作参考，但参考目标不等于图片落位。模型只从当前工作区已发布目录选择；Auto 可省略 model。默认 `quality=standard`、`resolution=1k`，只有用户明确要求档位才提高。需要透明底时明确 `background=transparent`、`outputFormat=png`，这只是请求，不能提前声称产物透明。

用户的当前执行授权与工具守卫为准；技能不增加权限、模型或预算，也不要求旧的方案确认。工具返回 processing/unknown 时追踪原任务，不自动换参数再次付费提交；只有真实结果与可见图片才能支持完成和视觉判断。
