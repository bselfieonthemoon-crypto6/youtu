# 非标准图片尺寸

`list_skills` 只列出技能，不代表读取正文。只有 `use_skill({name:"nonstandard-image-size"})` 返回成功且含正文，才可说已加载或已使用；读取失败时说明失败，不能根据名称猜测能力继续提交。

在用户当前请求明确接受“差不多尺寸”或“比例尽量靠近”等近似授权、**原话给出非标准比例/像素尺寸**（`1:3`–`3:1` 内的非常规比例如 `358×176`，或超出 `3:1`/`1:3` 的尺寸如 `658×176`）、或用户明确要求使用本 Skill 时，使用本流程。**常规预设比例（1:1、16:9、4:3、3:2、21:9 等）不需要本技能，也不要因此加载或追问。**“适配面板”本身不等于允许近似。普通生图、讨论尺寸、否定生成或表示不要近似，都不是触发条件。

读取 [原生比例与交付边界](references/workflow.md) 后，保留用户给出的目标像素宽高；像素太小时按 2、4、8 倍等倍数等比放大，直到达到原生最小面积和边长，把放大后的尺寸作为尺度参考，再按当前分辨率档位选择最接近的合法原生尺寸，比例优先。翻倍不改变比例，也不自动提高分辨率档位。当前原生图片尺寸解析支持 `1:3` 到 `3:1` 内的自定义比例，并为请求选择比例误差不超过 1% 的原生尺寸。小目标也会按原生最小面积请求较大的像素尺寸；只能如实报告实际提交或结果记录中的原生尺寸，不能声称像素尺寸接近用户的小目标，不能声称已经缩放。服务商最终输出另行以真实结果核对比例误差，不能预先保证它仍在 1% 内。

新图使用 `generate_image`，通过 `aspectRatio: "W:H"` 传递选定的合法比例，并设 `aspectRatioIntent:"approximate"`；其余必填内容照常提供，不能虚构 `width`、`height` 参数或新的尺寸工具。服务端会核对本轮实际读取技能的回执与用户的近似授权。编辑已有图片时，只有用户明确要改变比例才使用 `edit_image`，传真实源图 UUID、选定的合法比例和 `aspectRatioIntent:"approximate"`；否则保留源图比例。界面中明确选择的比例优先：若它与用户近似比例冲突，说明冲突并请用户选择，不覆盖界面选择。

在本技能的近似授权下，比例超过 `3:1` 时选择最近支持的 `3:1`，低于 `1:3` 时选择 `1:3`，提交前说明目标比例、实际采用比例和差异，不默默替换。**默认优先用“居中带 + 留白”承载目标比例**（见下节《尽量接近目标比例》），只有模型无法保证留白时才回退为把画面铺满合法画幅。明确调用本技能即采用此近似流程，不需要为已授权的最近比例再次确认；但用户要求精确尺寸或禁止改变比例时不能替代。这个替代规则只属于本技能，不改变普通生图的尺寸规则。

## 尽量接近目标比例（默认做法）

目标比例在 `1:3`–`3:1` 内时，**按其 `W:H` 提交**（如 `358:176`）：这是合法自定义比例，按本技能规则选用比例误差不超过 1% 的最近合法原生尺寸，**不替代、不追问额外授权**，也不要让用户从预设比例里选；如实报告实际像素，不承诺精确像素。**任何非标准比例都必须先 `use_skill` 读取本技能正文后再提交**（服务端会核对本轮技能回执）。

超出 `3:1` / `1:3` 时，不要把构图拉伸铺满整个合法画幅，而是**用合法画布承载目标比例的内容，事后裁掉留白即得到接近目标的精确比例**。占比与画布像素无关，可直接计算：

- 超宽（目标比例 > 3）：`横带高占比 = 3 / 目标比例`，内容为**整幅宽、居中**的横带，上下留白均分。例：`658:176 = 3.74:1` → 采用 `3:1`，横带约占画布高 `3 / 3.74 ≈ 80%`，上下各留约 10%。
- 超高（目标比例 < 1/3）：`竖带宽占比 = 目标比例 × 3`，内容为**整幅高、居中**的竖带，左右留白均分。

提示词必须写清：画布为选定的合法比例（如 `3:1`），**实际设计内容只占中间约 X% 的居中带**，带外的留白用与画面协调的纯色背景；用户要求透明时用 `background=transparent` 且 `outputFormat=png`。**不得把主体、文字拉伸铺满整幅画布**，文案与主体都必须落在带内。

回复里如实说明：实际提交的合法画布与内容带占比，并给出“裁掉留白即得目标比例”的可执行指引；不要声称已输出精确像素或已经裁切。若模型无法保证留白/透明边界，回退为“铺满合法画幅 + 说明比例差异”，不重复提交同一无效比例。

例如 `656×176 → 1312×352 → 2624×704`，放大参考仍为 `3.73:1`；因超过原生比例上限，采用 `aspectRatio:"3:1"`，说明“按最近支持的 3:1 生成，画面会比目标更高；比例相对目标约差 19.5%”。不要把原始 `656:176` 继续传给工具，也不要在提示词里同时要求该原始比例；原尺寸只作为目标说明。小目标的实际像素仍由原生生成决定，不能声称得到精确 `656×176`。新图默认 Low + 1K，不因适配而提高画质或分辨率。工具返回尺寸校验失败后，不重复提交同一无效比例，不声称正在生成。

本流程保留完整内容，不自动裁切、拉伸或写入原生画板。背景、GIF 和压缩是独立需求，不能因本流程自动加入或承诺。

同一任务的微调可沿用已经明确的近似授权；新的生成请求不继承。用户对新尺寸提出精确要求时，精确要求优先，本流程不适用。所有图片结果只交付到无限画布，不创建、写入或修改原生画板。
