# 背景去除与透明素材：按需细则

## 原图抠图
确认是哪个 image/canvas_image 与源 assetId，不能把预览缩略图或上次生成结果当源图。已有图片调用 edit_image 时明确 operation=generate、sourceUsage=edit、sourceAssetIds=[原图]、background=transparent、outputFormat=png。它直接提交已绑定源图的编辑任务；不存在源图、适用图片模型或 edit_image 工具时停止。新透明素材才使用 generate_image，并明确 background=transparent 与 outputFormat=png。

独立画布图片通常在原图旁生成新图片，保留原始资产；如果本轮绑定了原生设计目标，先读取目标、版本与源图对象，使用该设计的真实 target，不能意外写入其他画板或替换背景层。只有用户明确要求替换原对象时才带真实的替换对象 ID。提交前复述保留主体与编辑风险；工具完成前不能声称已生成。失败不得自行换模型或重启付费任务；异步 processing 也不等于失败。

## 原生背景与导出
canvas.background=null 或透明 PNG 只处理画布底色；全幅背景图层和照片内背景仍会存在。删除背景层是设计对象变更，应遵守目标范围与确认，不能把 opacity=0/几何 mask 当作主体分割。

## 质量与费用
透明边缘、半透明主体、阴影保留需看真实结果。API 不是逐像素抠图，产品标签、文字和纹理可能被重绘；严格原样保真应明确告知限制，不能把调用成功等同于视觉验收。服务端的 alpha 校验只证明有透明像素，不证明边缘质量。处理错误不能擅自付费重画或增加其他模型；保留原图并说明未达标位置。没有实际预览证据就不能声称“已抠干净”。
