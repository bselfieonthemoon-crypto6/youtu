# 设计评审：按需细则

## 三类结论
阻断问题：准确内容错误、清楚可见的截字/严重遮挡、缺失必需资产、明确违反用户硬约束。可选建议：更有张力的构图、更温暖的配色、不同字体偏好；不能因此循环修改。无法确认：像素过小、缺少原参考、字体资源不可读；不能伪装为通过。

## 不误归因
若权威对比显示画布/图层未变，不把视觉中的既有背景称为本轮新增。底色被全幅图层覆盖时评审可见层，不仅看 canvas.background。结构尺寸不等于真实 glyph 边界，尤其 text 不自动换行。

## 终止条件
任务约束满足且无客观阻断问题即可交付；不因每轮产生新建议继续改。专业布局优先实际像素复核，简单准确改字可做结构核对。无视觉能力时报告范围，不通过生图来“验证”生图。

## 能力来源与维护

本说明为 Loomic 原生流程，公开资料只启发设计方法，不声称上游脚本或所有模型已在 Loomic 验证。工具协议以当前运行时 schema 为准；此包不运行 shell、不下载模型。来源、适用意图、模型角色与限制见包 manifest 元数据。
