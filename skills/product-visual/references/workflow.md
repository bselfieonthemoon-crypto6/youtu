# 商品与产品视觉：按需细则

主图要主体完整、数量正确、背景不过度竞争；场景图的环境应说明使用场景，不添加不存在的附件。细节图只放大素材支持的结构；卖点图不补造认证、测试结果或功效。

对照实际结果核验瓶盖、边缘、孔洞、标签、商标、数量、透视与阴影。生成成功不等于外观正确；看不到局部细节时列为无法确认，不写“百分百还原”。固定真实产品参考比每张纯文字重新描述更可控。

有真实产品身份或用户指定参考时用 `edit_image`，传当前核验的 `sourceAssetIds` UUID；修改原图用 `sourceUsage=edit`，据原图做新场景用 `reference`。无源图、无可用模型或工具时不提交。图片工具不接受原生设计 target，不能用已有画板的 image 对象 ID 冒充 assetId。
