# 社交轮播图：按需细则

封面说清主题与看完收益，不编造夸张数字。中间可按问题→解释→证据或结论→对比→建议组织；一页一任务不必变成一页一句话。数据、条件与语义不能为视觉简洁被删。结尾可总结，不必永远促销。

每张 prompt 明确页码、角色、共用视觉 token 与本页独有内容。位图文案不可保证可编辑，须逐页对实际图片检查准确标题、序号、事实与阅读顺序。缺用户授权不增加页数；只改第三页就绑定第三页真实图片 UUID 用 `edit_image`，不能重做其余图片。

多页图片通过 `generate_image` 或带真实来源的 `edit_image` 独立交付无限画布，不传设计 target，也不声称已建原生 textbox/画板。逐页记录提交和完成状态，失败不整批重跑。
