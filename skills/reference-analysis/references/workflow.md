# 参考图分析：按需细则

## 拆解维度
焦点：最大/最亮/最留白处在哪里。比例：主体、文字和空白的相对面积。文字：哪些是标题、注释、标签，依靠什么区分。色彩：背景、强调和正文各承担什么任务。材质：哪些需要位图，哪些能原生形状实现。

## 合成参考
按维度组合，不把图 A 的色彩说成图 B 的特点。参考只是输入，不自动扩大为复制他人独特标记/布局或获取外部资源。让“借鉴留白”变成可检查的空白区域与对象边界，不编造精确像素。

## 能力不足
截图返回 URL 但模型未收到像素时只能使用已知结构。上传参考缺分辨率时指出不能确认项，不偷偷联网找相似图替代指定参考。
