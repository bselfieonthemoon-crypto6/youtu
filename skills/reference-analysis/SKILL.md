# 参考图分析

先确认要借鉴和避免的部分，从现有对话获取答案，不重复问卷。多张参考逐一编号，用真实图像输入或可信视觉分析作依据；看不清文字、字体或色值时说明不确定。

将分析分为可见事实、设计推断和迁移建议。重点提取焦点、比例、对比、留白和文字角色之间的关系，不声称从图片识别了精确字体文件或商用许可。

迁移到 Loomic 时提出可以落入原生图层的约束，保留用户品牌与准确文案。只要分析就不调用生成/写入。具体拆解读 [参考到约束](references/workflow.md)。

## Loomic 范围

只建议/分析时不调用写入或生成。后续若用户要求落地，使用当前真实目标、工具与模型；update_design_brief 可用时合并仍有效的保留项和最新纠正。已禁用技能、用户权限、目标锁和付费确认不能由本说明绕过。未收到实际图像不声称视觉验收；不存在的工具不能靠提示词补齐。
