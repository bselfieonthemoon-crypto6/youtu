# Prompt library third-party notices

Audit date: 2026-09-09. This file accompanies the reviewed prompt-text and remote-preview-URL snapshot. It does not grant new rights to any upstream work. Following the user's request, preview URLs are now displayed on demand directly from the original image hosts, without copying image files into Loomic storage.

- Discovery reference: [basketikun/infinite-canvas](https://github.com/basketikun/infinite-canvas), whose prompt presets link to the Image Prompt Registry. No Infinite Canvas frontend source code is copied by this integration.
- Normalized data provider: [yukkcat/image-prompts](https://github.com/yukkcat/image-prompts). Registry code and documentation are MIT; its upstream prompts and media are not relicensed by that MIT license.
- Text sources selected for the initial snapshot: [Banana Prompt Quicker](https://github.com/glidea/banana-prompt-quicker), [Awesome GPT-4o Image Prompts](https://github.com/ImgEdify/Awesome-GPT4o-Image-Prompts), [YouMind GPT Image 2](https://github.com/YouMind-OpenLab/awesome-gpt-image-2), and [YouMind Nano Banana Pro](https://github.com/YouMind-OpenLab/awesome-nano-banana-pro-prompts).
- Every included record retains its supplied author and original source URL. Source attribution identifies the collector and does not replace original-author attribution. An upstream label such as `Official` is preserved as supplied, not asserted to be an independent copyright verification.
- Loomic changes: classification and search metadata are normalized; image files are not stored or redistributed by our backend. Public source URLs are retained for on-demand browser display when a prompt card is visible or a gallery image is selected. Galleries are not automatically sent to image models or inserted as user reference assets. Prompt body text is not rewritten. The registry may have previously normalized line endings/whitespace and extracted text from source documents. These are adaptations of the distribution format, not new prompt authorship.
- DavidWu GPT Image 2, Freestylefly GPT Image 2, and ZeroLu Awesome GPT Image are link-only source entries in this initial integration; their prompt bodies and images are not included.
